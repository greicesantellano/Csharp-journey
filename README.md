# C# Journey

Minha jornada de estudos em C#.

Aqui registro exercícios, mini projetos e experimentos conforme avanço nos estudos de programação em C#.

## Projetos

### 01 - Energia Neurodiv

#Conceitos praticados:

- Variáveis
- Console.WriteLine()
- Console.ReadLine()
- int.Parse()
- if
- else if
- else
- Operadores lógicos (&&)

#Descrição:

O usuário informa seu nível de energia (0 a 10) e o sistema sugere uma atividade adequada ao nível de energia digitado.

### 02 - Guia Otaku de Emergência

#Conceitos praticados:

- Variáveis
- Console.WriteLine("");
- Console.ReadLine()
- int.Parse()
- switch case
- break e default

#Descrição:

O usuário seleciona uma opção de 1 a 5 baseada na lista apresentada e o sistema recomenda um anime pré determinado, com observações sobre o motivo da recomendação. Os animes foram adicionados de forma manual.

- Evoluir para interface gráfica simples
